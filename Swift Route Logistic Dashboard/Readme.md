# 🚚 Swift Route Logistic Dashboard | Power BI Project

## 📊 Project Overview

The **Swift Route Logistic Dashboard** is an interactive Power BI Business Intelligence project designed to analyze and monitor logistics operations, delivery performance, driver efficiency, hub capacity, and fleet utilization.

This dashboard transforms logistics data into meaningful business insights, helping management track operational KPIs, identify bottlenecks, and make data-driven decisions to improve delivery efficiency and customer satisfaction.

## 🎯 Business Objectives

- Monitor total orders and monthly order growth.
- Analyze On-Time Delivery Rate and Customer Satisfaction (CSAT).
- Evaluate hub performance and order processing capacity.
- Analyze driver experience, performance ratings, and delivery delays.
- Monitor vehicle utilization, maintenance, and breakdowns.
- Identify operational inefficiencies and improvement opportunities.

## 📂 Dataset

The project includes the following datasets:

- `Orders.csv` – Order details, delivery performance, customer satisfaction, and delays.
- `Hubs.csv` – Hub information and processing capacity.
- `Drivers.csv` – Driver details, experience, and performance ratings.
- `Vehicles.csv` – Vehicle information, status, breakdowns, and maintenance.

- Identified differences in hub capacity utilization.
- Analyzed driver experience against performance ratings.

- Compared order volumes across vehicle models.
- Tracked monthly logistics performance using KPI indicators.
